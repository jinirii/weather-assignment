Weather Forecast App Assignment


Description
This a project is a responsive weather forecast website. It displays the current weather along with a 7 day forecast for Calgary. Users visiting this website can view the high, low, and average. They will also see if it is sunny, rainy, and everything else in between.


Features
- Current weather
- 7 day forecast
- A switch between Celsius and fahrenheit
- Weather icons displaying conditions
- Automatic day and night themes
- Error and loading messages
- Respoonsive layout for different screens

Technologies Used for the Assignment
- HTML
- CSS
- JavaScript
- WeatherAPI

Used sources
- Given API
- Ai
- W3schools
- In class code examples

AI Usage
